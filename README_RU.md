# Наработки Infinity для onyx

Автор: **lunatik_kenny / KENNYx0903**. Репозиторий содержит исходники помощников, точные bytecode-дельты и рецепты интеграции принятых изменений по состоянию на R8 от 25.10.2026.

Полная документация и каталог компонентов — в [README.md](README.md). Это материалы для разработчиков, а не полный исходный код Android, не прошивка и не универсальный установщик.

Начните с [интеграции](docs/INTEGRATION.md), [воспроизводимости](docs/REPRODUCTION.md) и [плана проверок](docs/VALIDATION.md). Проверка файлов репозитория: `python3 tools/verify_repository.py`.

Закрытые APK/firmware, Google-приложения, ключи подписи и личные логи не публикуются. Наличие файла в историческом рецепте не означает, что этот эксперимент включён в R8: перечень принятого состояния зафиксирован в release/r8-manifest.json.
