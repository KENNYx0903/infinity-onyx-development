# Launcher integration

Includes the drawer label condensation toggle and historical icon/widget normalization recipes. Source ports must retain original text height and normal scaling for short labels, and update the setting live.

LawnIcons live refresh, generated monochrome normalization and weather/clock widget sizing are separate accepted changes. Themed-icon and launcher-popup blur experiments were canceled: do not reintroduce them from local prototype material. Only the outer Google search panel uses the additional native blur path in mode 3.
