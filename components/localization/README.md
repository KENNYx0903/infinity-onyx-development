# Localization and Settings labels

Includes resource/code transformation recipes for Russian coverage and English labels for new controls. Translate source resources in your tree where possible; binary resource IDs are specific to the original APK. AOD naming should be consistent across all three entry points.

Upstream application sources and translations retain their authorship; the repository contains transformations rather than full decoded app resources. Blur preview was canceled and should not be reintroduced by historical Settings edits.
